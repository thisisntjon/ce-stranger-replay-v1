# Security policy

## Scope

This repository contains a synthetic, offline replay fixture. It does not
contain the private Consumption Engine runtime, customer data, credentials, or
production deployment code. Reports about the private runtime or customer
systems cannot be investigated from this repository.

## Reporting a problem

Please report a suspected security issue privately to
`jon@simoneresearch.com` with:

- the affected commit or release;
- a clear description of the behavior;
- reproduction steps using only the public fixture; and
- any non-sensitive logs needed to reproduce it.

Do not include credentials, private data, or undisclosed vulnerability details
in a public issue. If the report concerns only a documentation or reproducible
fixture issue, a public issue is acceptable after checking that it contains no
sensitive information.

This policy does not promise a response time or a security bounty. The public
fixture is not a security boundary for the private product.
